# 🚀 Lab 09 - Object Detection using YOLOv8

## 📌 Overview
This lab demonstrates how to use the YOLOv8 (You Only Look Once) model for object detection on both images and videos. The implementation uses the Ultralytics YOLO library along with OpenCV and MoviePy for processing.

---

## 🧠 Key Concepts
- Object Detection using Deep Learning
- Pre-trained YOLOv8 Models
- Image Processing with OpenCV
- Video Processing using MoviePy

---

## ⚙️ Technologies & Libraries
- Python
- Ultralytics YOLOv8
- OpenCV
- Matplotlib
- MoviePy
- ImageIO
